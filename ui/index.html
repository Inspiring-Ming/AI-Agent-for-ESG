ESG Agent: what it does

You ask for an ESG metric. A language model (Claude) decides each next step: it finds which metric you mean, looks up how it is calculated, has the existing ESG system compute it, and explains the result. It never produces numbers itself — every value comes from the ESG system. Each step below shows the model's decision, its stated reason, and the part of the architecture it used.

Without the agent (existing ESG system)

  1. The analyst picks the company and year
  2. The analyst browses categories and picks a metric
  3. The analyst picks the calculation model
  4. The analyst presses calculate and reads the number

With the agent

  1. The analyst states the goal once
  2. The model discovers the metrics and chooses one (through MCP)
  3. The model finds the calculation model in the knowledge graph
  4. The ESG service computes the value; the model explains it
