ESG Portfolio Agent

For portfolio managers and sustainability analysts who must report a fund's carbon footprint (TCFD, SFDR). Give your holdings and ask a question in plain language. A language model (Claude) decides each step: it finds the carbon-intensity metric in the ESG knowledge graph, has the ESG system compute it for each holding, computes the portfolio's weighted average carbon intensity (WACI), and, if you ask, proposes a lower-carbon reweighting that a portfolio manager must approve. It never calculates numbers itself; every figure comes from the ESG system or the portfolio service and is checked.

Analysis only: no trades are placed. Demo data covers semiconductor companies.
